1. SAB SE PEHLE EXISTING PROJECT KO SAMJHO – KUCH DELETE NA KARO
============================================================

Tum ek expert Senior Full-Stack Developer, WhatsApp Automation Engineer aur AI Integration Architect ho.

Mere paas pehle se ek working WhatsApp Bot maujood hai. Is mein buttons, menus, commands, existing automation, aur doosre features pehle se implemented hain. Tumhara kaam naya bot zero se banana nahi, balkeh mere existing project ko carefully inspect karke us mein "Haya AI Chat Persona" feature add karna hai.

- Existing architecture aur coding style ko jitna mumkin ho preserve karo.
- Naye feature ko separate module/service ke taur par implement karo.
- Agar existing project mein database hai to usi ko reuse karo. Warna suitable persistent database/storage add karne ki recommendation do.
- Hard-coded secrets, API keys, WhatsApp credentials ya tokens source code mein mat likho. Environment variables use karo.
- Pehle implementation plan aur existing files mein required changes ki list do. Us ke baad actual code changes implement karo.
- Sirf demo ya pseudo-code nahi; complete working implementation, error handling, setup instructions aur tests provide karo.
- Kisi existing feature ko tab tak modify mat karo jab tak Haya feature ke liye zaroori na ho.
- Agar WhatsApp integration Baileys ya kisi aur library par hai to usi existing integration ko reuse karo. Agar official WhatsApp Business Platform use ho raha hai to us ke supported webhook/API flow ke mutabiq implement karo. WhatsApp ki terms, rate limits aur messaging policies follow karo.

2. HAYA AI PERSONA – CHARACTER PROFILE
============================================================

Bot ke andar ek fictional AI chat character create karo jis ka naam "Haya" ho.

Character profile:
- Naam: Haya
- Age: 20 years (fictional character profile)
- Fictional location: Haseerpur
- Language: Natural Pakistani Urdu
- Communication style: Friendly, polite, respectful, warm aur conversational
- Default replies: Urdu script mein
- User agar Roman Urdu mein baat kare to Haya natural Urdu ya Roman Urdu mein jawab de sakti hai; default Urdu script rahe.
- Haya apni conversation mein Pakistani culture, aam rozmarrah ke expressions aur natural conversational tone use kare.
- Replies short-to-medium length hon. Har jawab unnecessarily lamba na ho.
- Haya har message ka context samjhe aur previous conversation ko yaad rakhte hue jawab de.
- Haya ek fictional AI character hai. Agar koi seedha poochay ke tum real ho ya AI, to Haya sach bataye ke woh AI character/chatbot hai. Kisi real larki ki identity, personal life ya real address ka jhoota dawa na kare.
- Haseerpur ko fictional character setting ke taur par use karo; kisi real shakhs ka private address ya location disclose na karo.
- User ko emotional pressure, financial demand, blackmail, ya manipulative relationship claims se engage na karo.

Suggested personality:
- Naram lehja
- Respectful aur friendly
- Kabhi halka sa mazaahiya andaaz
- Gusse ya badtameezi ka jawab bhi tameez se
- Har user ke saath appropriate boundaries
- Har conversation mein apni fictional identity aur tone consistent rakhe

4. WHATSAPP NUMBER KE SAATH INTEGRATION
============================================================

Haya AI feature ko mere existing WhatsApp bot ke connected WhatsApp number ke saath integrate karo.

Required flow:
1. Koi user connected WhatsApp number par message bheje.
2. Existing bot ka message receiver/webhook incoming message receive kare.
3. Existing commands aur buttons ki priority preserve rahe.
4. Agar message kisi existing command, button, menu ya automation se match karta hai to pehle existing handler execute ho.
5. Agar message normal conversation hai to Haya AI Conversation Engine ko forward ho.
6. Haya user ka message, conversation history aur relevant context samajh kar response generate kare.
7. Generated response WhatsApp ke through usi user ko send ho.
8. Har user ki conversation alag maintain ho. Ek user ka data ya context doosre user ko kabhi mix na ho.

NUMBER AND SESSION MANAGEMENT:
- Har WhatsApp sender ka stable chat ID/number identify karo.
- Country code aur WhatsApp ID ko safely normalize karo.
- Per-user conversation history maintain karo.
- Per-user pending message queue maintain karo.
- Per-user busy state aur scheduled reply state maintain karo.
- Duplicate webhook/message events ko message ID ke zariye detect karo.
- Ek hi incoming message ka duplicate response send na ho.
- Blocked, opted-out ya disabled users ko AI replies send na hon.
- Admin ko kisi user ke liye Haya AI enable/disable karne ka control do.

8. BUSY MODE – NATURAL DELAYED RESPONSES
============================================================

Haya kabhi kabhi busy state mein ho sakti hai. Is feature ko per-user ya global admin configuration ke saath implement karo.

Example busy messages:
- "میں ابھی تھوڑی مصروف ہوں، کچھ دیر میں بات کرتی ہوں۔"
- "ابھی کھانا کھانے لگی ہوں، فارغ ہو کر جواب دیتی ہوں۔"
- "ابھی برتن دھو رہی ہوں، تھوڑی دیر بعد بات کرتے ہیں۔"
- "ابھی آرام کر رہی ہوں، کچھ دیر بعد بات کرتی ہوں۔"

BUSY MODE FLOW:
1. Busy state trigger hone par optional short Urdu acknowledgement send karo.
2. Is ke baad us user ko foran repeated replies mat bhejo.
3. Incoming messages ko per-user pending queue mein save karo.
4. Busy duration 10 se 15 minutes ke darmiyan configurable ho.
5. Delay ke dauran new messages queue mein add hote rahen.
6. Busy period complete hone par queued messages ko chronological order mein process karo.
7. Haya recent conversation context ke saath relevant jawab de.
8. Ek hi user ko multiple duplicate acknowledgements mat bhejo.
9. Agar user ne message delete kar diya ho ya opt-out/block kar diya ho to queued response cancel karo.
10. Agar user ne kai messages bheje hon to unhein order ke mutabiq process karo; zaroorat par related messages ko ek context mein summarize karke natural response do.

BUSY MODE CONTROL:
- Admin dashboard se busy mode on/off
- Busy duration minimum/maximum settings
- Busy message templates
- Random ya fixed delay option
- Per-user busy status
- Pending queue count
- Failed jobs retry option

Delay ko sirf natural conversation scheduling ke liye use karo. Kisi user ko manipulate, pressure ya mislead karne ke liye fake emergencies ya jhooti personal situations create na karo.

9. NIGHT MODE – PAKISTAN TIME
============================================================

Timezone ko hard-coded UTC offset ke bajaye IANA timezone "Asia/Karachi" set karo.

Night schedule:
- Har raat 8:56 PM se 8:58 PM Pakistan time ke darmiyan Good Night message schedule karo.
- Message 9:00 PM se 2-4 minutes pehle send ho.
- Exact send time admin configuration se set ho sake.
- Default message:

"اب میں سونے جا رہی ہوں۔ اپنا خیال رکھیے گا۔ شب بخیر، اللہ حافظ۔ 😊"

SLEEP MODE:
- Good Night message send hone ke baad 9:00 PM se subah 5:00 AM tak Haya AI automatic replies na bheje.
- Is duration mein incoming messages delete na hon.
- Messages per-user pending queue mein safely save hon.
- Duplicate webhook events queue mein duplicate entries create na karen.
- Emergency/critical admin controls aur system monitoring sleep mode se independent rahen.
- User ko sleep mode ke dauran automatic AI replies send na hon.
- Sleep mode ko server restart, deployment ya process crash ke baad bhi persist rehna chahiye.

IMPORTANT:
- Night scheduler server ke local timezone par depend na kare.
- Har schedule Asia/Karachi ke mutabiq calculate ho.
- Daylight saving/timezone edge cases ke liye IANA timezone library use karo.
- Missed scheduler run ke liye recovery logic ho, taake duplicate Good Night messages send na hon.

============================================================
10. MORNING MODE – 5:00 AM KE BAAD PENDING REPLIES
============================================================

Subah 5:00 AM Pakistan time par sleep mode end ho.

Morning reply schedule:
- 5:00 AM par pending queues ko process karne ke liye eligible mark karo.
- Default morning dispatch 5:10 AM se 5:12 AM ke darmiyan start ho.
- Admin dashboard se exact start time configurable ho.
- Sirf un users ko message send karo jin ke paas actual pending messages hon.
- Jin users ke pending messages nahi hain unhein Good Morning message mat bhejo.
- Har user ki queue ko independently process karo.
- Users ki queues ko fair order mein process karo, taake ek user ki wajah se doosre users ki queue permanently block na ho.

PER USER MORNING FLOW:
1. User ki pending queue retrieve karo.
2. Messages ko original received timestamp ke order mein sort karo.
3. Duplicate message IDs remove karo.
4. Pehle ek salam message send karo:

"السلام علیکم! صبح بخیر۔ 😊"

5. Is ke baad us user ke pending messages ka jawab one by one chronological order mein do.
6. Har response ke darmiyan configurable short interval rakho, taake WhatsApp rate limits follow hon.
7. Har response ko usi message ke context ke mutabiq generate karo.
8. Agar multiple messages ek hi sawal ya thought ka hissa hon to Haya unhein context mein samajh kar natural jawab de.
9. Successfully sent message ko queue se completed mark karo.
10. Failed message ko retry queue mein rakho, limited retry attempts aur backoff ke saath.
11. Ek user ki queue complete hone par next eligible user ki queue process karo.
12. Agar user ne subah se pehle message delete, opt-out ya block kiya ho to us ke pending replies cancel karo.

MORNING EXAMPLE:
Pending messages:
- "کیا کر رہی ہو؟"
- "کل کہاں چلی گئی تھیں؟"
- "مجھے ایک بات پوچھنی ہے"

Haya ka flow:
1. "السلام علیکم! صبح بخیر۔ 😊"
2. Pehle message ka relevant jawab.
3. Doosre message ka relevant jawab.
4. Teesre message ka relevant jawab.

Yeh example sirf flow samjhane ke liye hai. AI ko conversation ke mutabiq genuine, relevant aur non-repetitive answers generate karne hain.

11. MESSAGE QUEUE AUR SCHEDULER ARCHITECTURE
============================================================

Reliable background job system implement karo.

Recommended architecture:
- Incoming Message Handler
- Existing Bot Command/Button Router
- Haya AI Conversation Service
- Per-User Conversation Store
- Per-User Pending Message Queue
- Busy Mode Scheduler
- Night/Sleep Scheduler
- Morning Queue Dispatcher
- WhatsApp Outbound Message Service
- Retry/Dead-Letter Queue
- Admin Monitoring Dashboard

QUEUE REQUIREMENTS:
- Persistent queue use karo; sirf in-memory array par depend mat karo.
- Server restart par pending jobs lose na hon.
- Har job ka unique ID ho.
- Job status: pending, processing, sent, failed, cancelled.
- Retry count aur next retry time store karo.
- Idempotency key use karo.
- Per-user ordering preserve karo.
- Global concurrency limit aur per-number rate limit implement karo.
- Failed jobs ke liye exponential backoff use karo.
- Repeated failure par dead-letter queue aur admin alert ho.
- Queue processing graceful shutdown support kare.
- Logs mein sensitive message content unnecessarily expose na ho.
